# Deep Learning

- Course code: MCA10601A
- Course prerequisite: basic knowledge of machine learning, basic statistics knowledge, python programming

## Course Objectives

- To learn the basic concepts of deep learning
- To learn the fundamentals of neural networks
- To gain in-depth understanding about Convolutional Neural Networks, Recurrent Neural Networks, Autoencoders
- To get familiar with applications of deep learning

## Course Outcomes: CO604A._

1. **Explain** the basic concept of deep learning
2. **Illustrate** fundamentals of neural network
3. **Apply** Convolutional Neural Networks for real world applications
4. **Make use of** Recurrent Neural Networks for deep learning models
5. **Explain** the types of autoencoders for deep learning models
6. **Demonstrate** use of the concepts and applications of deep learning
