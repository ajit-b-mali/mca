# Image processsing in python

This project perform various operations on image

## For ME

### first setup

1. created venv
    `python3 -m venv venv`
2. activated venv -- need to do everytime
    `source venv/bin/activate`
3. installed **pillow**
    `pip install pillow`
4. deactivating venv
    `deactivate`
5. created requirement fil
    `pip freeze > requirements.txt`
6. downloading requirements
    `pip install -r requirements.txt`
