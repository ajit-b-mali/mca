# Web Programming

- Course code: MCA01603
- Course prerequisite: computer network, database management systems, basics of web

## Course Objectives

- To learn the fundamentals of web essentials and markup languages
- To use the client side technologies in web development
- To use the server side technologies in web development
- To understand the web services and frameworks

## Course Outcomes: CO603._

1. **Explain** the concept of static web pages using HTML and CSS
2. **Analyze** client side technology: JavaScript in detail
3. **Illustrate** the conceptual framework of bootstrap and wordpress
4. **Apply** recent web technologies: AngularJS and jQuery
5. **Utilze** the server side technologies for web development
6. **Demonstrate** use of web services
