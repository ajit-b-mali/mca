# Data Science

- Course code: MCA01602
- Course prerequisite: Basic programming skills(Python/R), Basic statistics knowledge

## Course Objective

- To study the fundamental concepts and methodologies of data science
- To understand the role of data science in business decision-making
- To apply data science concepts to real-world problems
- To develop and evaluate predictive models

## Course Outcomes: CO602._

1. **Compare** types of data and their characteristics
2. **Explain** data warehouse concepts and data preprocessing
3. **Apply** various classification algorithms to build solution for real world applications
4. **Make use of** clustering methods for commercially available datasets
5. **Implement** association rule algorithms to solve given problems
6. **Compare** appropriate data visualization method for effective visualization of data
