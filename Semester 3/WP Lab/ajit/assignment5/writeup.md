### **Assignment 5: Web Programming (WP)**

**Title: Design a Responsive Web Page using HTML, CSS, and Bootstrap**

---

#### **1. Objective**

To create a responsive web page layout that adjusts seamlessly across various device sizes using a combination of HTML, CSS, and Bootstrap.

---

#### **2. Introduction**

Responsive web design is a core concept in modern web development. It ensures that websites provide optimal viewing and interaction experiences across a wide range of devices, from mobile phones to desktops. A responsive website automatically adjusts its layout, font sizes, and element positioning based on the screen size.

HTML (HyperText Markup Language) is used to structure web content, CSS (Cascading Style Sheets) defines styling rules, and **Bootstrap** is a popular front-end framework that offers pre-built responsive components and a flexible grid system. With Bootstrap, developers can build mobile-first web pages more efficiently.

This assignment focuses on combining these three technologies to create a basic responsive web page with a header, navigation bar, content section, and footer.

---

#### **3. Materials and Methods**

**Tools/Technologies Required:**

* HTML5
* CSS3
* Bootstrap (v4 or v5)
* Text Editor (e.g., VS Code, Sublime)
* Web Browser (e.g., Chrome, Firefox)

**Methodology:**

* Structure the web page using semantic HTML elements.
* Use Bootstrap's container and grid classes for layout responsiveness.
* Style specific elements using custom CSS rules.
* Integrate Bootstrap's responsive navigation bar and content areas.

**Key Components of the Web Page:**

* **Header**: Contains page title or logo
* **Navigation Bar**: Responsive menu using Bootstrap classes
* **Main Content**: Two-column layout (e.g., text and image) that stacks on smaller screens
* **Footer**: Information such as copyright

---

#### **4. Procedure**

**Step-by-step Algorithm:**

1. Set up the HTML page with `<!DOCTYPE html>` and basic structure.
2. Link the Bootstrap CSS and optionally Bootstrap JS via CDN in the `<head>` section.
3. Create a navigation bar using Bootstrap’s `navbar` component.
4. Add a main container with rows and columns using `.container`, `.row`, and `.col-*` classes.
5. Include responsive text, images, and buttons within the layout.
6. Apply additional styling via external CSS for colors, spacing, and typography.
7. Add a footer using a `<footer>` tag and style it with Bootstrap utility classes.
8. Save and open the web page in different screen sizes to test its responsiveness.

---

#### **5. Results**

**Observation:**

* The web page automatically adjusts its layout depending on the screen size.
* Navigation collapses into a hamburger menu on smaller devices.
* Columns stack vertically on smaller screens and align side-by-side on larger screens.
* Custom styles are consistently applied throughout the layout.

**Outcome:**
A fully responsive and visually appealing web page has been successfully built using HTML, CSS, and Bootstrap. The page demonstrates modern design practices and adapts well to both desktop and mobile environments.
