# Software Testing and Quality Assurance

- Course Code: MCA01601
- Course Prerequisite: Basic knowledge of Software Development Methodologies

## Course Objective

- To know the importance of software testing and quality assurance
- To study white box and black box testing techniques
- To get acquainted with various testing types
- To study selenium tools used for automation testing

## Course Outcomes: CO601._

1. **Illustrate** basics of software quality assurance, and quality control
2. **Design** test plan, test cases and defect repository using real world applications
3. **Apply** the concept of white box and black box testing techniques
4. **Explain** various software testing types
5. **Summarize** software test automation concepts
6. **Apply** software testing automation concepts using open source Selenium
